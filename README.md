# Infinity Recargas — Site

Site público da Infinity Recargas (vitrine + tutoriais). O briefing completo do
projeto está em [CLAUDE.md](./CLAUDE.md).

## Desenvolvimento

```bash
npm install
cp .env.local.example .env.local # preencha as variáveis
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Stack

Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 4, 100%
estático (SSG), hospedado na Vercel.
